# Public AI Development Sessions

Chronological index of every archived AI development session for
[`sugie/wildlive`](https://github.com/sugie/wildlive). Newest at
the top.

Each entry links to the human prompt (English translation of the
original), the visible AI conversation (also English translation),
the merged Pull Request, and the bilingual development reports.

For the policy, layout, and validator, see
[`README.md`](README.md).
