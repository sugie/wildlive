pgvector バージョンの整合

本番は pgvector 0.8.5、dev image pgvector/pgvector:pg17 は pgvector 0.8.6 を同梱。両方 0.8.x line で、現在 WildLive が設計している範囲では API 互換。ADR-0005 では pgvector patch を pin しない — アプリケーションコードで特定 pgvector 機能に依存している箇所がまだ無いため。将来、vector index コード等が特定 patch に依存する場合、その task で image を具体 tag に pin し、新規 ADR に記録する。
