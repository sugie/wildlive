Task 008 — iOS タイトル画面 (Milestone 001, UI-first)

Project: WildLive  ·  日付: 2026-08-14  ·  AI Agent: Claude Code (claude-opus-4-7[1m])  ·  Status: main に merge 済み

人間による介入 (Human intervention)

WildLive を今後 UI-first の順序 (UI → Interaction → Game Experience → Domain/API → Infrastructure) で開発する方針変更を人間 (repository owner) が宣言し、Xcode + Swift + SwiftUI で iOS Simulator 上に WildLive の最初のタイトル画面を表示することを AI に指示した。 backend / API / DB / production infrastructure は一切触れない条件。AI が Version 0 を local commit として作成し、Simulator screenshot をチャットに inline 表示、人間がそれを見て "OK Make PR" と応答 — push と PR 作成を許可 (merge は許可していない)。本レポートは PR レビュー用の write-up。

目的 (Objective)

まず「見えるもの」を先に ship する: iOS Simulator で本当にブートする WildLive のタイトル画面。それだけ。game loop なし、タイトル画面から先の遷移なし、network なし、persistence なし、auth なし、backend なし、data model なし、third-party framework なし。
