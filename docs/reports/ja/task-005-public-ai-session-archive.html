Task 005 — Public AI Development Archive

Project: WildLive  ·  日付: 2026-08-14  ·  AI Agent: Claude Code (claude-opus-4-7[1m])  ·  Status: main に merge 済み

人間による介入 (Human intervention)

WildLive の開発に使った prompt と AI との可視インタラクションを、 AI-assisted software development の公開参考資料として repository に アーカイブする、という判断は人間 (repository owner) が行った。 language policy も人間の決定: 開発は日本語で行われることが多いが、 公開 archive は英訳のみ、一方で docs/reports/ 配下の bilingual HTML report は従来どおり日英両方で作成する。AI (Claude Code) は archive の構造・validator・governance 更新を設計 / 実装し、Task 005 (本 task) 自身を最初の archive record として bootstrap した。

Session note

最初の 2 回、仕様の送信は chat channel の途中で切れて届いた。AI は それらの turn では repository に一切変更を加えず、欠けているセクションを 推測で埋めるのではなく完全な再送を依頼した。3 回目の送信で仕様が全部 届き、そこから本 task を開始した。この visible な履歴は docs/ai-sessions/task-005-public-ai-session-archive/transcript.en.md に English として残してある — 本 task が実際にどう展開したかの一部として。

目的 (Objective)

WildLive を、AI-assisted software development の公開参考資料に すること。今後 AI が milestone を実装するたびに、 「人間がどう prompt したか」「AI が visibly どう応答したか」 「どんな command が走ったか」「どの PR / merge に到達したか」を、 repository を読むだけで追えるようにする。

今回は governance と infrastructure のみ。 database migration、Eloquent model、game logic、game API は 本 task では実装しない。

本 task で定めた language / transparency policy

  • Archive は English only。 prompt / transcript は日本語 original の faithful English translation。docs/reports/ 配下の bilingual HTML report は従来どおり日英両方で作る。
  • 翻訳 faithfulness。 要約・美化・要件の追加 / 削除・意味変更を行わない。code、command、path、URL、identifier、error message は原文維持。
  • Visible only。 private chain-of-thought や hidden reasoning は含めない。archive するのは人間が chat 上で見えたもの + verified な tool activity のみ。
  • 捏造禁止。 取得できなかった部分は Not captured または Not available in the public session record と明記。
  • Security。 credential / token / cookie / .env value / GitHub Secret value を絶対に含めない。source 中に登場した場合は [REDACTED]。validator の secret scanner がこれを強制する。

既知の課題 / 未解決事項 (Problems / Known Limitations)

  • Session capture は human-driven。 本 MVP の validator は sanitize と publish は担うが、capture 自体はまだ自動化していない。Claude Code が安定した structured session transcript を公開したら、後続の task で wire できる。undocumented な Claude Code behaviour を前提に framework を作ることは今回避けた。
  • Post-merge metadata field は optional。 merge_commit、ci_status、post_merge_ci_status は shipped metadata.json の中で null のまま残ってもよい。それらはいずれも link された PR page から検証できるし、必要なら小さな follow-up PR で backfill できる。
  • 過去 milestone は遡って archive しない。 Task 001〜Task 004 は session record を持たない。それらは Git 履歴、PR、bilingual HTML report から復元可能。

今回実装していないこと (What was NOT done)
