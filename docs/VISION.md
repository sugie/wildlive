# Vision

## WildLive

**WildLive — An AI-made live MMO**

WildLive is a living, persistent, text-only multiplayer animal world.

The player does not need to remain online. Hunters continue their assignments over real time, and players return later to discover what happened.

The shared world also advances independently of any single player.

## Product goals

WildLive should feel:

- alive
- mysterious
- persistent
- social without requiring synchronous play
- simple enough to understand immediately
- deep enough to produce stories players want to share

The absence of illustrations is intentional. Text should leave room for imagination and allow the world to expand rapidly.

## Autonomous-development goal

The project itself should demonstrate that AI agents can:

- select or receive small tasks
- implement them
- test them
- document them
- review them independently
- create pull requests
- publish development reports
- eventually support operation of the game

Human work should focus on vision, guardrails, major product decisions, security, and irreversible production decisions.

## Public development

The repository is public.

Development history is part of the product.

The project should make it possible to measure and publish metrics such as:

- AI commits
- human commits
- merged PRs
- automated tests
- human interventions
- autonomous-development streak
